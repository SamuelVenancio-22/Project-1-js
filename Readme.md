# 💱 Conversor de Moedas

Um projeto de conversor de moedas desenvolvido com **HTML, CSS e JavaScript**, criado com o objetivo de praticar meus conhecimentos em desenvolvimento Front-End e dar meus primeiros passos com JavaScript.

O projeto permite trabalhar com a conversão entre diferentes moedas, explorando conceitos fundamentais da programação e da criação de interfaces web.

## 📸 Sobre o projeto

O Conversor de Moedas foi desenvolvido como parte da minha jornada de aprendizado em programação, colocando em prática conhecimentos de estruturação de páginas, estilização e lógica de programação com JavaScript.

Mais do que criar uma aplicação funcional, este projeto representa minha evolução como desenvolvedor Front-End.

## 🚀 Tecnologias utilizadas

- **HTML5:** estruturação dos elementos da página.
- **CSS3:** estilização, layout e organização visual da interface.
- **JavaScript:** lógica de conversão, manipulação do DOM e interação com o usuário.

## ✨ Funcionalidades

- Conversão entre diferentes moedas.
- Seleção das moedas de origem e destino.
- Entrada de valores para conversão.
- Exibição dos resultados na interface.
- Formatação de valores monetários.
- Interface simples e intuitiva.

## 📚 O que estou aprendendo

Durante o desenvolvimento deste projeto, estou praticando conceitos importantes, como:

- Manipulação do DOM com `document.querySelector()`.
- Eventos com `addEventListener()`.
- Utilização de variáveis e constantes.
- Estruturas condicionais com `if` e `else`.
- Operadores matemáticos.
- Manipulação de valores de elementos HTML.
- Formatação de moedas com `Intl.NumberFormat()`.

## 🎯 Objetivo do projeto

Meu objetivo é desenvolver minhas habilidades em JavaScript e construir uma base sólida para evoluir como desenvolvedor Front-End.

Este projeto faz parte do meu processo de aprendizado e representa um dos meus primeiros passos na criação de aplicações interativas para a web.
